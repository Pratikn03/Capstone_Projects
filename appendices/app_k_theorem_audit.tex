\chapter{Theorem Audit Register}
\label{app:theorem-audit}

No draft theorem rows remain in the defended theorem register.  Historical
draft surfaces are archived only and do not contribute to the active theorem
count.  The active register is generated from
\path{reports/publication/theorem_promotion_matrix.csv}; each promoted row has
a result card with statement status, assumptions, proof file, code anchor,
tests, artifacts, artifact hashes, manuscript anchor, and claim boundary.

\section{Promotion Classes}
\begin{description}
  \item[Flagship theorem] Main defended result.
  \item[Flagship corollary] Derived result whose proof burden is inherited from
    a flagship theorem.
  \item[Flagship lemma] Supporting runtime law with a narrow proof.
  \item[Archived only] Historical text excluded from the defended register.
\end{description}

\section{Falsification Conditions}
A promoted theorem must be demoted or patched if any referenced proof file,
code anchor, test file, artifact, artifact hash, or claim-boundary note becomes
missing or stale.  The CI-facing validator is
\path{scripts/validate_theorem_promotion.py}.
